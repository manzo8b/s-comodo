# Privacy

*Last updated: 25 October 2026.*

This page describes the services currently used by **S-COMODO**, a static website hosted on GitHub Pages and curated by Marcelo Fernandez. It is an English-language explanation of the current implementation; it is **not a declaration of full GDPR compliance**.

## Hosting and site services

S-COMODO does not currently operate user registrations, newsletters, contact forms, advertising or its own traffic analytics. GitHub Pages may process technical connection information for site delivery. See [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Public comments

Comments use **HTML Comment Box**, an external service. It is loaded only when you choose **Show comments** below an article. The provider may receive technical connection details, set cookies and process what you submit. Public comments may display your chosen name and message. Do not publish anyone's confidential or personal information.

See the [HTML Comment Box privacy notice](https://www.htmlcommentbox.com/static/privacy.pdf) and the [comment guidelines]({{ '/en/comments/' | relative_url }}).

## External links and corrections

External websites use their own privacy policies. GitHub Issues are public and require a GitHub account: do not submit private information in an issue.

## Data protection rights

Applicable data protection laws may give rights of access, rectification, erasure and objection, and a right to complain to a regulator. The project **has not yet published a dedicated private contact address** for these requests. Do not use public comments or GitHub Issues for confidential requests. The contact detail and legal review remain to be completed.

The Italian [Privacy page]({{ '/privacy/' | relative_url }}) describes the same site services in greater detail.
