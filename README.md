# S-COMODO
Blog indipendente by Marcelo Fernandez.

**S-COMODO è un blog editoriale indipendente in evoluzione**, con articoli italiani e contenuti in altre lingue, riferimenti alle fonti e dichiarazioni sull'uso dell'IA. L'elenco dei contenuti effettivamente disponibili è quello pubblicato sul sito; le prime note storiche SC001/SC002 non rappresentano più l'intero catalogo.

**[Leggi gli articoli](https://manzo8b.github.io/s-comodo/)** · [Metodo editoriale](https://manzo8b.github.io/s-comodo/metodo/) · [Segnala un problema](https://github.com/manzo8b/s-comodo/issues)

Sito pubblico: https://manzo8b.github.io/s-comodo/

L'italiano è la lingua principale. Articoli con firma *Redazione S-COMODO* e supporto dichiarato dell'intelligenza artificiale.

## GitHub Pages
Repository pubblico. Settings → Pages → Build and deployment → Source: GitHub Actions.

## Sicurezza
Non caricare file di `_drafts/` né fascicoli documentali riservati; il controllo in `scripts/check_publication.py` richiede approvazione editoriale esplicita per ogni nuovo post. La pagina privacy descrive le funzioni attive e i commenti restano disabilitati fino alla moderazione preventiva.

## Illustrazioni
Le due immagini SVG attuali sono **provvisorie**: sostituirle con le illustrazioni WebP approvate, conservate nel pacchetto privato v1.6, prima del lancio pubblico.

## Impaginazione editoriale — novembre 2026

`assets/css/reading-edition.css` applica il tema chiaro: testata serif, filetti sottili e colonna di lettura da 700 px. Logo e favicon coordinati sono in `assets/brand/`. `assets/js/reading-edition.js` aggiunge l'indice dei capitoli ai dossier con almeno tre sezioni, l'avanzamento della lettura e contenitori scorrevoli per le tabelle. Gli articoli rimangono leggibili anche senza JavaScript.

La prima pagina italiana mostra gli articoli italiani; l'archivio conserva tutte le lingue e le edizioni inglese e spagnola restano disponibili. La modifica dell'impaginazione non cambia testi, fonti o approvazioni degli articoli.
