# Privacidad

*Actualizado: 28 de octubre de 2026.*

S-COMODO es un sitio estático alojado en GitHub Pages y dirigido por Marcelo Fernandez. No dispone actualmente de cuentas de usuario, boletines, formularios propios de contacto, publicidad ni herramientas propias de analítica de tráfico.

GitHub Pages puede tratar información técnica para ofrecer las páginas. Consulta la [política de privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Comentarios

La plataforma externa **HTML Comment Box** se carga solo después de que el lector pulse **Mostrar comentarios**. El servicio puede procesar datos técnicos, utilizar cookies y mostrar públicamente los datos aportados en cada comentario. Lee la [política de privacidad del proveedor](https://www.htmlcommentbox.com/static/privacy.pdf).

## Informes públicos y protección de datos

Los avisos por GitHub Issues son públicos. No los utilices para enviar datos confidenciales. La legislación aplicable puede reconocer derechos sobre tus datos personales y el derecho a reclamar ante una autoridad de control.

**El proyecto todavía no publica una dirección privada para estas solicitudes**, y está pendiente la revisión legal de este procedimiento. Esta página explica el funcionamiento actual; no acredita cumplimiento normativo. Consulta también la [página de privacidad italiana]({{ '/privacy/' | relative_url }}).
