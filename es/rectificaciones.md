# Rectificaciones

Corregimos errores factuales cuando se detectan, incluso si no afectan a la conclusión general del ensayo. Las correcciones sustanciales se documentan con fecha y explicación.

Indica el artículo, el pasaje cuestionado y, si es posible, un documento verificable.

[**Comunicar un error por GitHub ↗**](https://github.com/manzo8b/s-comodo/issues/new?template=correccion-es.yml)

Los informes publicados mediante GitHub Issues **son públicos y requieren una cuenta**. No incluyas información confidencial o datos personales. Este no es un canal privado de protección de datos.
